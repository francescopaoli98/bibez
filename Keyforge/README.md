# Keyforge (Ki Forge)

Progetto Unreal Engine 5 del gioco. Il piano completo è in `../PROGETTO2.md`.

## Cosa c'è qui

| Voce | Contenuto |
|---|---|
| `SETUP_PC.md` | Passi per preparare il PC (una volta sola) |
| `.gitignore` | Esclude i file generati da Unreal |
| `.gitattributes` | Manda i file binari su Git LFS |
| `Source/` | Codice C++ del gioco (dopo la creazione del progetto) |

## Regole

- La logica di gioco sta in **C++**. I Blueprint sono solo sottili, per impostare valori.
- Si lavora una fase alla volta, come in `PROGETTO2.md`, sezione 7.
